# PIER 7 — ブラウザFPS（自前サーバー版）

夕暮れのコンテナ港を舞台にしたフリー・フォー・オールのFPSです。
この版は Node.js サーバーで配信し、同じルーム名を入れた人どうしでネット越しに対戦できます。

## すぐに遊ぶ

```bash
cd server
npm install
npm start
```

ブラウザで `http://localhost:8080` を開きます。同じネットワークの別端末からは `http://<このPCのIP>:8080`。
ポートは環境変数で変更できます: `PORT=3000 npm start`

インターネットに公開する場合は、Node.js が動くホスティングに `server/` フォルダをそのまま置き、`npm start` で起動してください。HTTPS で配信すると WebSocket も自動で `wss://` になります。

## フォルダ構成

```
server/            そのまま動く配布物
  server.js        静的配信 + WebSocket リレー（ルーム・位置・イベントの中継）
  public/index.html  ゲーム本体（ビルド済み・1ファイル）
src/               ゲームのソースコード
  config.js        武器・移動・マッチ・Bot難易度の数値
  map.js           マップ生成（倉庫・事務所・コンテナ・クレーン・階段・アイテム配置）
  textures.js      手続き生成テクスチャ（アスファルト・コンテナ鋼板・木箱など）
  physics.js       AABB 当たり判定・段差乗り越え・レイキャスト・部位ヒットボックス
  nav.js           コライダーから自動生成する多層ナビグリッド + A*
  player.js        自キャラの移動（ダッシュ/しゃがみ/ジャンプ/落下ダメージ）と武器操作
  weapons.js       弾数・連射・リロード（ショットガンは1発ずつ）・拡散とブルーム
  viewmodel.js     一人称の銃（揺れ・反動・リロード/ポンプ/ボルト・ADS・近接・投擲アニメ）
  models.js        銃6種・ナイフ・グレネード・兵士モデル（ローポリ、描画呼び出しを結合）
  avatar.js        他プレイヤー/Bot の補間・歩行/しゃがみ/死亡アニメ・名札
  bots.js          Bot AI（索敵・反応時間・照準誤差・バースト射撃・横移動・経路探索・投擲）
  effects.js       曳光弾・着弾火花/粉塵・弾痕・薬莢・爆発・マズルフラッシュ光源
  audio.js         WebAudio による全効果音の合成（音声ファイルなし）
  net.js           通信アダプタ（claude.ai ルーム / WebSocket / オフライン）
  game.js          全体制御（ホスト選出・命中判定・ダメージ・キル・ラウンド・アイテム）
  hud.js, input.js, main.js, template.html
build.mjs          ソースを1ファイルにまとめるビルドスクリプト
```

## 改造してビルドし直す

```bash
npm install            # three / esbuild
node build.mjs         # → dist/pier7.html と server/public/index.html を生成
```

## オンライン同期のしくみ

- 各プレイヤーは自分の「状態」（位置・向き・体力・武器・キル数と、直近の射撃/命中/キル/グレネード/チャットのイベント）を約30回/秒で送ります。
- ルーム内で ID が最も小さい人が「ホスト」になり、Bot・マッチ時間・ラウンド進行を担当します。ホストが抜けると次の人が引き継ぎます。
- 命中判定は撃った側が行い、ダメージは撃たれた側（Bot はホスト）が適用します。
- サーバーは中継のみで、ゲームロジックはブラウザ側で動きます（気軽に遊ぶ用途向けで、不正対策はありません）。

## 設定と公平性

メニューと一時停止画面の「設定」から変更できます。

- 操作：マウス感度、ADS中の感度、上下反転、ADS・しゃがみ・ダッシュの「押している間／押して切り替え」
- キー割り当て：全操作をキーボードかマウスボタン（左右・ホイール・4・5）に割り当て可能。重複は入れ替え、Esc と Ctrl/⌘ は不可
- タッチ：ボタンの配置（ドラッグで編集）、大きさ、不透明度、視点感度
- 映像：画質（高・標準・軽量）、描画解像度、アンチエイリアス、視野角 65〜90°、歩行時のカメラの揺れ、FPS表示
- サウンド：全体・効果音・環境音・通知音
- HUD：クロスヘアの色と形、HUDの大きさ、チャット表示

対戦の有利不利に関わる部分は変更できません。

- 反動：全武器に共通の反動（`src/config.js` の `FORCED_RECOIL`）が上乗せされ、ADSやしゃがみでも減らず、Botにも同じ反動がかかります
- 影・煙・霧はどの画質でも表示、足音だけを大きくする設定はなし
- 保存された設定は読み込み時に許容範囲へ補正されます（`src/settings.js` の `SCHEMA`）

## 操作

| 操作 | キー |
|---|---|
| 移動 / ダッシュ / ジャンプ / しゃがむ | WASD / Shift / Space / C |
| 射撃 / ADS | 左クリック / 右クリック |
| リロード / 武器切替 | R / 1・2・3・Q・ホイール |
| グレネード / 近接 | G / V |
| スコア / チャット / メニュー | Tab / Enter / Esc |

スマホ・タブレットでは画面左ドラッグで移動、右ドラッグで視点、ボタンで射撃などができます。
